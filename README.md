# VibgyorHackTeamMAIS
Aarnav, Jeevesh, Rudransh and Aarya from Vibgyor

1. The program reads and scans PDF(s) and images of legal documents.
2. These are then sent to AI models for analysis using Nemotron API.
3. The API analyses and returns major risks and a key summary of the legal document provided.
4. This is then displayed to the users with the risks highlighted to help them understand the terms of any agreement.
5. The application supports multilingual capability (for english, hindi and french as of now).
